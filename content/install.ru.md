Плагин — это бандл DSH: пакет с `cordis.patch.yml`, который добавляет в
харнесс инструменты, сервисы или элементы интерфейса. Поставить его можно тремя
способами, и все три ведут к одному и тому же пакету.

Пошаговые скриншоты есть на странице каждого плагина — там же лежит готовый
адрес вида `github:org/repo#commit`.

## 1. Через CLI

```bash
dsh plugin add github:extreme-russian-dsh-fandom/dsh-github-cli
```

`dsh plugin add` принимает имя пакета с версией, git-адрес, tarball или
абсолютный путь. Адрес `github:org/repo` ставит последний коммит ветки по
умолчанию; чтобы закрепить ревизию, добавьте `#<commit>`.

## 2. Через DSH Desktop

**Plugins** в боковой панели → **Add plugin** → вставить адрес → **Install**.

## 3. Из каталога

Чтобы плагины появлялись во вкладке **Discover**, DSH должен знать адрес
индекса — это один файл:

```
https://extreme-russian-dsh-fandom.github.io/dsh-index.json
```

Порядок:

1. **Settings → Experimental plugins** → включить **Custom plugin indexes**
   (список надо развернуть целиком, функция лежит в нём).
2. **Plugins → Discover**:
   - если источников ещё нет — **Add index source**;
   - если источник уже есть — список источников → **Manage index sources…**.
3. Вставить адрес индекса и нажать **Add**.

Так вы получаете ещё и проверку совместимости: DSH сверяет версию плагина с
вашей версией харнесса и не даст поставить заведомо несовместимый.

Каталог пересобирается раз в сутки, поэтому свежий релиз появится не мгновенно.
Кнопка обновления в Discover перечитывает индекс сразу.

## Обновление и удаление

Ставьте и снимайте плагины подкомандой `dsh plugin`; полный актуальный список
подкоманд смотрите в `dsh plugin --help` — набор меняется от версии к версии.
Внутри `dsh plugin` работает обычный pnpm, поэтому каталог профиля остаётся
обычным `package.json` + `pnpm-lock.yaml`, и сломанную установку всегда можно
починить руками.

## Если не ставится

- **`dsh: installation rejected`** — DSH откатил установку и вернул
  `package.json` и `pnpm-lock.yaml` в исходное состояние. В сообщении обычно
  указана причина; полный лог — в выводе команды.
- **Плагин не появился** — проверьте, что он включён в профиле: установка и
  активация — разные шаги.
- **Каталог не читается** — DSH ждёт от источника `http(s)`-адрес без логина,
  пароля и `#`-фрагмента. Если индекс отдаёт 404, проверьте URL целиком,
  включая `/dsh-index.json`.
