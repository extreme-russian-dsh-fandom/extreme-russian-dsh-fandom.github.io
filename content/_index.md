Plugins for [DeepSeek Harness](https://github.com/deepseek-ai), built by the
members of the [extreme-russian-dsh-fandom](https://github.com/extreme-russian-dsh-fandom)
organization.

The catalog is generated from the organization's repositories: version, commit
and icon come from the repositories themselves and are never typed by hand. The
same set is available to the machine — add [`dsh-index.json`](/dsh-index.json) as
an index source in DSH and the plugins show up under **Discover**.
